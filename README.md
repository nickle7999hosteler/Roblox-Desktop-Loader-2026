## FAQ

### What is XCutors and what does it do?

XCutors is a collection of tools designed to run Lua scripts within the Roblox game client. It bundles multiple popular executors and a universal loader into a single interface for easy management.

### Is XCutors safe to use on my computer?

We distribute unmodified, clean files. However, running any third-party code carries inherent risks. We recommend using a reputable anticomponent and understanding that game modifications can violate Roblox's Terms of Service.

### How often are the executors updated?

We aim to provide updates for each bundled executor within 24-48 hours of their official public release. The XCutors loader will notify you when updates are available for download.

### Why do I need a password to extract the archive?

The archive password is a basic measure to deter automated scanning and distribution. It is provided in the installation instructions and is not a form of copy protection.

### Can I add my own custom executor to the launcher?

Yes, the XCutors interface allows you to manually add external executor executables to the menu. This feature is for advanced users who need to integrate specialized tools.

### Does XCutors work on Windows 11?

Yes, XCutors is designed to be compatible with both Windows 10 and Windows 11. It requires standard Windows .NET Framework and Visual C++ redistributables to function properly.

### What should I do if an executor fails to launch?

First, ensure you are running XCutors as Administrator. Check your anticomponent logs to see if it quarantined a file. You can also try reinstalling the package and verifying the file integrity with the provided checksums.
